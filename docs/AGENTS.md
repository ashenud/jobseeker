# Documentation-specific Codex rules

- Numbered product requirements exist only in `docs/milestones/`.
- Numbered execution prompts exist only in `docs/prompts/`.
- Do not add a second progress ledger; link to `IMPLEMENTATION_STATUS.md`.
- Milestones own requirements and acceptance; prompts own task execution; patterns
  own reusable implementation guidance.
- Do not embed another Codex execution prompt in a milestone document.
- New local links and backticked repository paths must resolve.
- Update `docs/README.md` when adding a new documentation category.
- Do not check an acceptance box or write `DONE` without validated evidence.
