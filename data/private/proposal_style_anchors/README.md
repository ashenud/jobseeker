# Proposal style anchors

This directory is reserved for owner-supplied proposal examples used only to
calibrate writing style. Milestone 03 does not include any proposal history.

Keep future anchors local and private. Do not commit contact details, client
briefs, private feedback, credentials, inbox exports, editable source files,
high-resolution production assets, or unsupported claims. Style anchors never
become evidence: every factual proposal claim must still resolve to an eligible
record in `portfolio_manifest.yaml`.
